# Meeting Conflict

컴퓨터소프트웨어학과 캡스톤 프로젝트 — 팀 로딩중

## 프로젝트 소개

회의록에서 주요 결정 사항을 추출하고, 기존 결정과의 중복·충돌을
검토하여 사용자가 해결 방법을 선택할 수 있도록 돕는 시스템.

## 배포 주소

- 프론트엔드: https://meeting-conflict.pages.dev
- 백엔드 상태 확인: https://meeting-conflict-api.onrender.com/api/health

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 프론트엔드 | React, TypeScript, Vite |
| 프론트엔드 개발 환경 | Node.js |
| 백엔드 | Java 25, Spring Boot 4.1.1 |
| 인증·데이터베이스 | Supabase Auth, Supabase PostgreSQL |
| AI 연동 | Gemini API |
| 프론트엔드 배포 | Cloudflare Pages |
| 백엔드 배포 | Render, Docker |
